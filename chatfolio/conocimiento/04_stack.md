# Stack y habilidades de Lleyton Murphy

- Motores: PostgreSQL, MySQL, SQL Server.
- Técnicas: JOINs, CTEs, subconsultas, GROUP BY/HAVING, window functions y modelado en tercera forma normal (3FN).

## BI y Excel (habilidades de Lleyton)
- Power BI (Power Query y DAX), Tableau y Looker Studio.
- Excel avanzado: tablas dinámicas, XLOOKUP y macros VBA.
- Dónde lo usó: tablero de Vaca Muerta Operations Intelligence (DAX, ranking de 38 operadoras), modelo estrella y dashboard ejecutivo de TechStore, reporte financiero automatizado con VAN/TIR.

## Python (habilidades de Lleyton)
- Librerías: pandas, NumPy, SciPy, Matplotlib, Seaborn, Streamlit y Jupyter.
- Prácticas: pipelines ETL, validación de datos y tests con pytest.
- Dónde lo usó: pipeline de Vaca Muerta Analytics (+2.400 pozos, curvas de Arps con SciPy, app en Streamlit), modelos de machine learning de rendimiento de pozos, modelo logístico de arena de fractura.

## Análisis de datos (habilidades de Lleyton)
Calidad de datos, análisis exploratorio (EDA), KPIs, estadística, forecasting, regresión, backtesting, detección de anomalías y storytelling con datos.
Ejemplo: validó con backtesting las estimaciones de reservas de Vaca Muerta (alrededor de 9 % de error a 36 meses) y detecta pozos anómalos frente a su curva esperada.

## Automatización e IA (habilidades de Lleyton)
- Plataformas: n8n, Make, APIs REST y webhooks, RPA básico.
- IA: Claude API, OpenAI API, agentes de IA, RAG y flujos con aprobación humana (human-in-the-loop).
- Integraciones: Gmail, Slack, HubSpot, Airtable, Google Sheets, WhatsApp Cloud API y Telegram.
